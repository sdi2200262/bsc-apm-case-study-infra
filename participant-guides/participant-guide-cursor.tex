\section{Welcome \& Introduction}

Thank you for participating in this research study. Your participation is essential for evaluating how effectively modern AI-powered development tools support Spec-Driven Development (SDD) workflows.\newline\newline
The goal of this study is to compare how different AI-assisted frameworks perform on a practical, well-defined coding task. Please be assured that \textbf{you are not being tested}; the AI tools are. All data, including incomplete or non-functional code, is valuable to this research.

\subsection*{Data Privacy \& Anonymity}
All data that you will submit will be handled with strict confidentiality. Your name or any personal identifiers will not be linked to the data. The research artifacts you will provide will be used exclusively for this academic research and will be anonymized in any resulting publications. You have been assigned a unique participant ID for this study, which you must include in your submission file names as described in the submission instructions.\newline\newline
\textbf{Data Handling:} All submitted chat logs will be encrypted using a secure encryption key before being stored in a publicly accessible dataset repository. This ensures that while the dataset structure is transparent, the actual content of your interactions remains confidential and cannot be read without the encryption key, which is held only by the research team. By proceeding, you consent to the anonymous collection and use of this data as described.

\section{Study Overview}

\subsection{Your Task}

Your task is to research an existing legacy PHP codebase and implement a new feature in an existing Python codebase based on your findings. You will receive a detailed \textbf{Product Requirements Document (PRD)} as the sole source of truth for the specification, guiding both you and the AI tools.

\subsection{Your Tools}

You will complete this task \textbf{twice}, each time using a different AI-coding framework (e.g., APM, Spec-kit, Cursor's Plan Mode). Sessions will be \textbf{time-boxed and isolated on separate branches}. Between sessions, you will submit your code changes, chat logs, and a brief survey.
\begin{mainbox}{Learning Effects Note}
We acknowledge that performing the task twice may introduce learning effects. To mitigate this, some participants will begin with Tool A, others with Tool B. This counterbalancing aims to ensure fair assessments across the study.
\end{mainbox}

\subsection{Your Time}

Each session is strictly time-boxed to \textbf{three (3) hours}. It is important that you stop at the 3-hour mark, regardless of whether you are finished. Committing unfinished work is a perfectly valid and expected outcome.

\section{AI Tools: Setup \& Instructions}
\label{sec:ai-tools}

Before starting your sessions, familiarize yourself with your assigned tools. Below are setup instructions and usage guidelines for each tool.

\subsection{APM in Cursor}

\subsubsection*{Description:}

\href{https://github.com/sdi2200262/agentic-project-management/}{\textbf{Agentic Project Management (APM)}} is designed to enhance your development process by decomposing specifications into actionable tasks and coordinating their execution across multiple AI agents; aiming to improve efficiency and context management.

\subsubsection*{Setup Instructions:}

\begin{itemize}
    \item Ensure you have \inlinecode{npm} installed on your system.
    \item Install the \inlinecode{agentic-pm} package globally using the following command:
    \begin{codebox}
npm install -g agentic-pm
    \end{codebox}
    \item Once installed, use the \inlinecode{apm init} command within your working directory's root (alongside the other codebases) and select \inlinecode{Cursor}.
\end{itemize}

\subsubsection*{Familiarization:}

To get acquainted with APM, visit the \href{https://agentic-project-management.dev}{official documentation} which includes video tutorials and getting started guides before starting your timed session.

\subsection{Spec-kit in Cursor}

\subsubsection*{Description:}

\href{https://github.com/github/spec-kit}{\textbf{Spec-kit}} is another AI-powered development framework designed to enhance the specification and planning stages of software development, ensuring a spec-first approach throughout the implementation process.

\subsubsection*{Setup Instructions:}

\begin{itemize}
    \item Ensure \inlinecode{uv} has been installed and set up on your system.
    \item Install the \inlinecode{specify-cli} using their official recommended installation command:
    \begin{codebox}
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git
    \end{codebox}
    \item Once installed, use the \inlinecode{specify init <your-project-name>} command within your working directory's root (alongside the other codebases) and select \inlinecode{Cursor}.
\end{itemize}

\subsubsection*{Familiarization:}

To get acquainted with Spec-kit watch this \href{https://www.youtube.com/watch?v=a9eR1xsfvHg}{tutorial} and/or read the \href{https://github.github.com/spec-kit/}{official documentation} before starting your timed session.

\subsection{Plan Mode in Cursor}

\subsubsection*{Description:}

Cursor's \textbf{Plan Mode} offers a streamlined implementation of Spec-Driven Development principles by emphasizing a "first-plan-then-execute" workflow. It enables your AI assistant to break down tasks into manageable steps before execution.\newline\newline
After your plan has been finalized in Plan Mode, you may switch to Agent Mode if you need to further iterate on task execution. Alternatively, you can save the plan locally from Plan Mode and start a new chat in Agent Mode to execute it there.

\subsubsection*{Setup Instructions:}

No additional setup is required beyond having Cursor 2.0+ installed. To enable Plan Mode simply select it in the chat mode modal:

\section{Session Workflow (Step-by-Step)}

This section explains the session workflow in which you are to attempt to complete your task. Please follow these steps in order.

\subsection{Ensure Environment is Set Up}

Following \hyperref[sec:your-environment]{Section~\ref*{sec:your-environment}}, ensure you have installed Cursor and that you have correctly set up your environment with all dependencies installed and the required repositories.\newline\newline
Opening Cursor in your designated workspace directory would look like this:
\begin{center}
    \includegraphics[width=1\textwidth]{assets/cursor/cursor-setup.png}
\end{center}

Verify that all the base dependencies are installed by running:
\begin{codebox}
/PATH/TO/YOUR/PYTHON3 --version   # Check Python version
uv --version                      # Check UV version  
npm --version                     # Check NPM version (for APM)

# Check Python codebase dependencies (silent success, errors shown)
cd eclass-mcp-server
/PATH/TO/YOUR/PYTHON3 -c "import mcp"
/PATH/TO/YOUR/PYTHON3 -c "import requests"
/PATH/TO/YOUR/PYTHON3 -c "import bs4"
/PATH/TO/YOUR/PYTHON3 -c "import dotenv"
\end{codebox}

\subsection{Session 1: Tool A}


\subsubsection*{Initialize Git and Create Branch:}
    
    Ensure you're starting from a clean state and create an isolated branch:
    \begin{codebox}
cd eclass-mcp-server                # go to implementation codebase root
git checkout main                   # switch to main branch
git checkout -b tool-a-attempt      # create new branch for Tool A patch
    \end{codebox}

\subsubsection*{Before you start working:}
    
    \begin{itemize}
        \item Launch your first assigned AI tool (Tool A) following its setup instructions in \hyperref[sec:ai-tools]{Section~\ref*{sec:ai-tools}}.
        \item \textbf{Thoroughly read the} \inlinecode{Specification.md} (the PRD) provided alongside this guide.
        \item Use the \textbf{default task prompt} provided with the PRD to initiate your first chat.
        \item \textbf{Note the start time}; it will be used to track your request statistics and session duration.
        \item Use \textbf{only} your assigned Tool A for AI assistance during this session.
        \item Start the timer and get to work!
    \end{itemize}

    \begin{mainbox}{Important Note on Model Selection}
    For study validity, all participants \textbf{must} use \textbf{Cursor's Composer 1} model for the \textbf{entire duration} of both Tool A and Tool B sessions.
    \end{mainbox}

\subsubsection*{Work Until Completion or Time Limit:}
    
    \begin{itemize}
        \item Continue working on the task for up to \textbf{3 hours}.
        \item \textbf{Stop at the 3-hour mark}, even if you haven't completed the task.
        \item Alternatively, stop when you have fully completed the task (if before 3 hours).
    \end{itemize}

\subsubsection*{Create Code Patch:}
\label{sec:creating-patch}

    After the 3 hour mark or upon task completion, generate your solution patch file for this session (replace \verb|{PID}| with your participant ID, e.g., \verb|P001|):
    \begin{codebox}
git add . && git commit -m "Tool A solution"                # commit changes
git diff main tool-a-attempt > {PID}_tool_a_solution.patch  # create patch file
    \end{codebox}

\subsubsection*{Export AI Interaction Logs:}
    
    Follow the specific instructions in \hyperref[sec:exporting-logs]{Section~\ref*{sec:exporting-logs}} to export chat conversations and retrieve request statistics. Organize these in a \verb|{PID}_tool_a_logs/| folder.
    
\subsubsection*{Clean Up and Ensure Isolation:}
    
    Return to main branch and remove the solution branch:
    \begin{codebox}
git checkout main
git branch -D tool-a-attempt
    \end{codebox}
    
    \begin{mainbox}{Git Note}
Feel free to use Git for version control during your session. However, ensure that you \textbf{do not modify the main branch directly}. All code changes related to your task should be committed to your isolated branch (\inlinecode{tool-a-attempt} for Tool A and \inlinecode{tool-b-attempt} for Tool B) before concluding the session.\newline\newline
\textbf{Important:} After creating the patch file, \textbf{immediately save/move it to a safe location outside your repository} (e.g., your desktop or a dedicated submission folder). \textbf{Do not} delete your branch until you have saved the patch file and exported all logs; these files will be lost if you delete the branch first.
    \end{mainbox}

\subsubsection*{Complete Tool A Survey:}
\label{sec:tool-a-survey}

Fill out the brief \href{https://forms.gle/dPJY5vYg6XwU4T5b8}{Tool A post-session survey}.

\subsubsection*{Session 1 Checklist:}
\label{sec:session-1-checklist}
Before moving to Session 2, ensure you have completed the following:
\begin{itemize}
    \item Created the patch file \verb|{PID}_tool_a_solution.patch| and deleted the \inlinecode{tool-a-attempt} branch.
    \item Collected AI interaction logs and organized them in \verb|{PID}_tool_a_logs/| folder:
    \begin{itemize}
        \item Exported all chat conversations as \inlinecode{.md} files in \verb|{PID}_tool_a_logs/chats/| subfolder.
        \item Exported and filtered your token usage as \verb|{PID}_tool_a_requests.csv| in \verb|{PID}_tool_a_logs/stats/| subfolder.
    \end{itemize}
    \item Completed the \href{https://forms.gle/dPJY5vYg6XwU4T5b8}{Tool A post-session survey}.
\end{itemize}

\section{Exporting AI Interaction Logs from Cursor}
\label{sec:exporting-logs}

To export your AI interaction logs (chat conversations and AI request statistics) from Cursor, follow these steps for both sessions:

\subsection{Export Chat Conversations}

When using Tool A or Tool B, you may open multiple chat conversations in Cursor. For example, with APM, you will typically open at least three conversations: \textbf{Setup Agent}, \textbf{Manager Agent}, and at least one \textbf{Implementation Agent}. For Spec-kit or Plan Mode, the number of conversations may vary depending on your usage of these tools.\newline\newline
It is crucial to retain \textbf{all workflow conversations} for analysis. Do not delete any conversations during your sessions. \underline{If a conversation is accidentally deleted, please notify the researcher immediately.}\newline\newline
To export each conversation, follow these steps:
\begin{itemize}
    \item For each chat conversation opened during your session, navigate to that specific chat.
    \item In the top-right corner of the chat window panel, click on the \textbf{three-dot options menu}.
    \item From the dropdown menu, select the \textbf{"Export Chat"} option.
    \begin{center}
        \includegraphics[width=1\textwidth]{assets/cursor/cursor-export-chat.png}
    \end{center}
    \item Choose a location on your local machine to save the exported \inlinecode{.md} file.
\end{itemize}

\noindent Save the exported \inlinecode{.md} file using the \textbf{strict naming format}:\newline
\texttt{\{PID\}\_tool\_\{a$|$b\}\_chat\_\{NN\}.md}\newline
where \texttt{\{PID\}} is your participant ID (e.g., \texttt{P001}), \texttt{\{a$|$b\}} is the tool identifier, and \texttt{\{NN\}} is the chat number starting from \texttt{01} (e.g., \texttt{P001\_tool\_a\_chat\_01.md}, \texttt{P001\_tool\_a\_chat\_02.md}).\newline\newline
\noindent Organize your exported files as follows:

\begin{itemize}
    \item Create a subfolder \verb|{PID}_tool_a_logs/chats/| for your chat exports
    \item Save all chat conversation \inlinecode{.md} files in this subfolder
    \item Save the filtered request statistics CSV in \verb|{PID}_tool_a_logs/stats/| subfolder
\end{itemize}
\begin{mainbox}{Important Chat Export Note}
Consider exporting conversations \textbf{immediately after completion} during your session to avoid accidental deletions. For example, export APM's Setup Agent conversation right after the setup phase.
\end{mainbox}

\subsection{Retrieve AI Request Statistics}

To retrieve your AI request statistics from Cursor, follow these steps:

\begin{itemize}
    \item Login to your \href{https://cursor.com}{Cursor} account and go to the \href{https://cursor.com/dashboard}{Cursor Dashboard}.
    \item On the sidebar, click on the \textbf{"Usage"} tab to access your usage statistics. 
    \item Click on the \textbf{"Export CSV"} button located at the top-right corner of the Usage page.
    \begin{center}
        \includegraphics[width=1\textwidth]{assets/cursor/cursor-dashboard.png}
    \end{center}
\end{itemize}

\noindent This will immediately download a CSV file containing your AI request statistics to your local machine. This file contains AI requests made across all your sessions. \newline\newline
To isolate the requests made during your specific session, use the provided python script\newline\inlinecode{filter\_csv\_by\_datetime.py} with the \textbf{start time} you noted at the beginning of each session and rename the output file using the \textbf{strict naming format}: \texttt{\{PID\}\_tool\_\{a$|$b\}\_requests.csv} (e.g., \texttt{P001\_tool\_a\_requests.csv}).\newline\newline
For example, if your session started on 2025-11-06 at 14:30 in the Europe/Athens timezone:
\begin{codebox}
python3 filter_csv_by_datetime.py usage-events.csv 2025-11-06 14:30 Europe/Athens
\end{codebox}

\begin{mainbox}{Important Timing Note}
This will create a filtered CSV file containing only requests from that point onward (e.g.,\newline \inlinecode{usage-events\_filtered\_2025-11-06\_14:30\_Europe\_Athens.csv}).\newline\newline
Run the filtering script \textbf{immediately after completing your session} to ensure the CSV includes all requests from the session start up to your last AI request. If you wait too long before filtering, additional requests from other activities may be included.
\end{mainbox}

\subsection{Organize Logs for Submission}

Save the exported chat conversations and filtered request statistics in a dedicated logs folder. Create the following folder structure using your participant ID:

\begin{codebox}
{PID}_tool_a_logs/
    chats/
        {PID}_tool_a_chat_01.md
        {PID}_tool_a_chat_02.md
        ...
    stats/
        {PID}_tool_a_requests.csv
\end{codebox}

# Replace {PID} with your participant ID (e.g., P001)
